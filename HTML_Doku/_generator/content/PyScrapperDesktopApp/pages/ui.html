Central styles

Design/Design.axaml is the largest XAML file at {{stat:loc:Design/Design.axaml}} lines and defines colours, brushes and control styles for the whole app. It is pulled in by App.axaml. Individual windows only add layout around it, no colours of their own.

Icons exist twice, split into Assets/DarkMode and Assets/LightMode. On a theme change the code swaps the bitmaps — see MainWindowViewModel.UpdateHideIcon(), which hooks App.Current.ActualThemeVariantChanged.

Custom title bar

TitleBarControl replaces the window bar of the operating system: dragging, minimise, maximise and close are implemented in it. Windows that embed the control run without system decoration accordingly.

Design mode

Many view models start with if (Design.IsDesignMode) return;. The preview renderer in the IDE creates an instance without a server, configuration or signed-in user existing. The guard stops HTTP calls and file access from running in that state. New view models whose constructor touches AppData or the network need the same line.
