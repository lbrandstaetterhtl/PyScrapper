PyScrapperDesktopApp

The Windows client of PyScrapper. Avalonia 11.3 on .NET 9, MVVM with the CommunityToolkit, LibVLC for playback. The app keeps no data of its own — everything goes over HTTP to the LocalServer.

The four places that explain everything

  1. App.StartupFlow() — the startup sequence from config through login and launcher to the main window.
  2. AppData — the static state every view model reaches into directly.
  3. Database — every data operation as an HTTP call.
  4. MainWindowViewModel — the dispatcher for practically every user action.
