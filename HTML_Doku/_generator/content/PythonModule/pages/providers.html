Providers

One module per platform — and, for the three most involved ones, a package. From the outside they all look the same; on the inside they differ a lot, from a hundred lines of regex to a browser that hunts for a playback token or a client that impersonates a VR headset to get at YouTube's formats.

Two files in the packages are dead

Youtube/Youtube.py ({{stat:loc:providers/Youtube/Youtube.py}} lines) and Soundcloud/Soundcloud.py are the pre-split originals. Neither __init__.py imports them and nothing else references them, so the functions that are actually called are the ones in the small modules. Youtube.py in particular still uses yt-dlp, which the live code no longer does — reading it to understand current behaviour will mislead you.

ITAG handling for YouTube Music

YouTube identifies each stream variant with a numeric itag. ITAG_PRIORITY ranks them, ITAG_RESOLVE_TYPE maps an itag to audio or video. That is how the browser path picks a variant without any format list — it reads the itag out of the URL of the responses it observed.

The contract

A new provider module needs two functions with exactly this shape, otherwise the mappings in models/settings.py will not bind:

FunctionParametersReturns
search search_term, filters, session, top list[dict] with url, title, thumbnail, type, identifier
getMediaInformation request: ProviderResultRequest ProviderResult

Search is invoked through asyncio.to_thread, so it is deliberately written synchronously. Blocking calls inside it are fine; starting your own event loop is not.

Adding a provider

  1. Create the module under providers/ (or a package with an __init__.py that re-exports the two functions) and import it in providers/__init__.py.
  2. Add a value to ProviderTypes.
  3. Create the alias list VALID<NAME>NAMES and register it in SUPPORTEDPROVIDERS — otherwise validateProviders() rejects it.
  4. Register it in PROVIDER_GETRESULTS_MAPPING and, if there is a search, in PROVIDER_SEARCH_MAPPING.
  5. Restrict the allowed hostnames through Validate.special.validateHostPro(). That is the SSRF guard and every existing module does it this way.

Browser sniffing

Where a regex will not do, MediaBrowser takes over. It starts Chromium through Playwright, hooks every response and sorts them into mediaList or unknownList. The decision is made by helpers.utils.isMediaResponse() from the URL, the content type and Playwright's resource type. A provider subclasses it and overrides _handleResponse — that is where Soundcloud detects Widevine and raises DRMProtectedMediaError, and where the YouTube Music browser picks its itag.

actions is a list of dictionaries, so a sequence of clicks and waits works as written: Soundcloud dismisses the consent banner and then the modal close button. The selectors that are shared across providers live in browser/models.py (PLAY_BUTTON_SELECTORS, COOKIE_ACCEPT_SELECTORS, AD_SKIP_BUTTON_NAMES).

Cookies are loaded from the Mozilla-format cookies.txt on start and written back on stop, so logins survive across runs.
