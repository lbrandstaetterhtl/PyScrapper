Program flows

Every path through the server, step by step. Click a step — or use prev/next — to see what happens there, which errors it can raise and where it can go from here. The tabs switch between flows.

How to read these

The spine on the left is the happy path in execution order. Dashed boxes are decision points; red ones are error exits. The buttons under „Where it can go from here“ jump to the step they name, which is how the branches and the error paths are reachable — they are not part of the linear sequence.

Each step links into the source where there is a function to point at, so the flow answers „what happens“ and the module page answers „how“.
