Captcha OCR

A small Rust extension that reads the text out of Bandcamp's image captchas. Python imports it as ocr and calls one function, img_to_text(image_path, ocr_dir), which returns a short list of candidate strings, most likely first.

What it does

The input is the JPEG Bandcamp shows when it suspects a bot: a few letters and digits on a coloured background. The crate does not read the whole image at once. It first separates the letters into single 28×28 crops, classifies each crop with a small convolutional network, and then combines the per-letter guesses into whole strings with a beam search. That way a letter the network is unsure about still produces several plausible answers instead of one wrong one.

The caller gets at most max_candidates strings (currently {{stat:max_candidates}}). Bandcamp's captcha form is then simply tried with each of them in turn.

No training code in this repository

The crate only runs inference. model.safetensors was trained elsewhere; the trainer is not part of the project. LocalServer/testing_captcha_ocr.py still calls a captcha_ocr.train() function from that earlier stage and does not work against the current module.
