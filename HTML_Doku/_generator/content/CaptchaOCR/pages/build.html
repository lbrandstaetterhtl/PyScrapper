CaptchaOCR / build

Build and run

The crate is compiled into a Python wheel with maturin. There are three ways to get it into the Python environment the server runs in.

Three ways to install

SituationDo this
Windows, local server pip install --force-reinstall PythonModule\providers\ocr\ocr-0.1.0-cp39-abi3-win_amd64.whl
Linux or macOS, local server cd LocalServer/docker/captcha_ocr_source
pip install maturin
maturin develop --release
Docker cd LocalServer/docker
docker compose up -d --build

maturin develop builds and installs into the active virtual environment in one step. To get a wheel file instead, use maturin build --release; the result lands in target/wheels/ and is named ocr-0.1.0-cp39-abi3-<platform>.whl.

The first build downloads and compiles candle and the image crates and takes several minutes; later builds are incremental. Rust is installed with rustup (curl https://sh.rustup.rs | sh -s -- -y --profile minimal), and the compiler needs a C toolchain (build-essential on Debian/Ubuntu, the MSVC build tools on Windows).

One wheel per platform, not per Python

pyproject.toml enables pyo3/abi3-py39, so the wheel uses only the stable Python ABI and runs on every CPython from 3.9 on. A wheel is still bound to the operating system and CPU: the one in the repository is win_amd64 and will not install on Linux or on ARM.

In the server image

LocalServer/docker/Dockerfile has a first stage based on python:3.11-slim that installs the build tools, rustup and maturin, copies the crate and runs maturin build --release --out /wheels. The second stage installs that wheel with pip before the server's own requirements. Rust is therefore not part of the final image.

The model directory

The wheel contains only code. At runtime img_to_text needs a directory with config.json and the weights file it names. In this project that is PythonModule/providers/ocr/, which the Bandcamp provider finds relative to its own file. The directory has to be writable if config.json is missing, because the module then writes a default one.

When it does not work

SymptomCause
ModuleNotFoundError: No module named 'ocr'The wheel is not installed in the environment the server runs in. Check with python -c "import ocr" using that interpreter.
is not a supported wheel on this platformThe Windows wheel on Linux/macOS, or a wheel built for another CPU. Build it locally with maturin.
Candidates look randomThe weights file was not found and the network runs with random weights — check the ocr_dir and model_name.
Model returns N classes, vocab has M charactersvocab_str in the config does not match the trained model.
unknown devicedevice in the config is not cpu, cuda or metal; the last two also need a candle build with that feature.
Always one character too fewTwo letters touch in the captcha and are segmented as one; see Image to letters.
