Suche & Download Dialog (ScrapWindow)
Dialog-Fenster zum Suchen nach Videos auf verschiedenen Plattformen (YouTube, Bandcamp, etc.) und zum Starten des Downloads. Zeigt Sucherergebnisse mit Vorschaubildern.

Funktionen:

Ergebnis-Anzahl (1-25)
Format-Auswahl (MP3/MP4)
Suche Button: API aufrufen
Ergebnisse mit Thumbnails
Multi-Select: Mehrere Videos
Scrap Button: Download starten
Workflow:
1. Benutzer gibt Suchtext ein
2. Klickt "Search"
3. API sendet HTTP POST /search
4. Ergebnisse anzeigen
5. Videos auswählen
6. "Scrap" klicken → Download
