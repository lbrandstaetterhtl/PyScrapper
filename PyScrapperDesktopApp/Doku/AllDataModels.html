2. Request/Response DTO Modelle (Server-Kommunikation)

Diese Modelle werden für die JSON-Serialisierung bei der HTTP-Kommunikation mit dem Python-Backend verwendet.

classDiagram
    class DownloadRequestData {
        +string Provider YouTube,Bandcamp,Suno,Archive
        +string Url Link zum Video
        +string Mediatype mp3,mp4
        +string Filename Speichername
        +string Download_path Zielpfad
    }
    
    class SearchRequestData {
        +string Provider Platform
        +string Search Suchbegriff
        +int Top Anzahl Ergebnisse 1-25
    }
    
    class SearchResultItem {
        +string identifier Eindeutige ID
        +string url Video URL
        +string thumbnail Thumbnail URL
        +Bitmap ThumbnailBitmap Lade Bitmap
        +string title Video Titel
    }
    
    class SearchSuccessResponse {
        +string Provider Plattform
        +string Query Suchbegriff
        +List Results SearchResultItem Liste
    }
    
    class NormalResponse {
        +string Id Download ID
        +string Message Statusmeldung
    }
    
    class ProgressSuccessResponse {
        +string Id Download ID
        +string Status Running,Finished,Error
        +float DownloadProgress Prozentangabe
        +string ErrorMessage Fehlermeldung
        +long TotalBytes Gesamtgroesse
        +long DownloadedBytes Heruntergeladen

    class HealthResponse {

    }

3. Entity Modelle (Geschäftslogik)

Diese Modelle repräsentieren die Hauptentitäten des Systems: Medien, Playlists, Filter, etc.

classDiagram
    class DownloadedMedia {
        +int Id Eindeutige ID
        +string Identifier Original Identifier
        +string Title Angezeigter Name
        +string Url Quelle URL
        +string MediaType mp3,mp4
        +DateTime DownloadedAt Zeitstempel
        +string DownloadPath Dateipfad
        +bool IsPlayable Kann abspielbar sein
        ---
        +SetHighestId() ID automatisch setzen
        +SetTitle() Titel aus Datei Name
    }
    
    class Playlist {
        +int Id Eindeutige ID
        +string Name Playlist Name
        +string Description Kurzbeschreibung
        +List~int~ MediaIds Enthaltene Medien
        +List~int~ PlayableMediaIds Nur abspielbar
        +int Count Anzahl Medien
        ---
        +SetHighestId() ID automatisch setzen
        +SetPlayableMediaIds() Filtert spielbar
        +AddMedia() Medium hinzufuegen
        +RemoveMedia() Medium entfernen
    }
    
    class Settings {
        +int Id Eindeutige ID
        +string DownloadPath Speicher Dir
        +string ServerUrl http://127.0.0.1:8765
        +bool DarkModeEnabled Theme
        ---
        +SetDefaultSettings() Defaults setzen
    }
    
    class MediaFilter {
        +string SearchQuery Suchtext
        +ObservableCollection~string~ MediaTypes Filter
        +DateTimeOffset StartDate Von Datum
        +DateTimeOffset EndDate Bis Datum
        +bool IsPlayable Nur spielbar
        ---
        +ApplyMediaFilter() Filter anwenden
        +ClearFilter() Filter zurueck
        +BuildMediaFilter() Filter erstellen
    }
    
    class AppData {
        +static DownloadedMedias Alle Medien
        +static PlayableMedias Spielbare Medien
        +static Playlists Alle Playlists
        +static CurrentMediaFilter Aktiver Filter
        +static Settings Konfiguration
        ---
        +AddDownloadedMedia() Medium hinzu
        +RemoveDownloadedMedia() Medium weg
        +AddPlaylist() Playlist erstellen
        +RemovePlaylist() Playlist loeschen
        +MediaAlreadyExists() Existiert bereits
    }

6. Response Status Zustände und Enumerationen

Mögliche Werte und Zustände in den verschiedenen Modellen.

Download Status Werte: "Running", "Finished", "Error"
MediaType Werte: ".mp3", ".mp4"
Provider Werte: "suno", "youtube", "bandcamp", "archive"
Logger Type Werte: "INFO", "ERROR", "DEBUG"
Server URL: http://127.0.0.1:8765
API Endpoints:
  • POST /download - Download starten
  • POST /search - Suche durchführen
  • GET /download/progress/{id} - Fortschritt prüfen
  • GET /health - Server Status
